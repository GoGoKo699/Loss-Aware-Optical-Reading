## Reproduce

From the repository root, use a fresh environment and a new output path:

```bash
python -m pip install -r audits/theory-01/requirements.txt
python scripts/verify_import.py
python scripts/reproduce.py --output results/runs/theory01-regression
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python audits/theory-01/diagnostics.py \
  --root . --output ../theory01-independent-run
```

Both output directories must be new. The diagnostic checks pinned mathematical
source hashes before and after execution. It intentionally reproduces known
baseline defects; a PASS means its 998 tests reproduced the declared findings,
not that every canonical function is correct over every accepted input.

The script's independent full-Hermitian numerical dual uses SciPy HiGHS linear
programs with spectral cuts and a checked PSD repair. It does not use a dedicated
SDP solver. The analytic proofs, not finite tests, justify universal statements.
No interval arithmetic or formal proof assistant was used.
