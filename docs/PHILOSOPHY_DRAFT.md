# Inspiration and working philosophy

**Draft for owner approval.** This text is an editorial draft, not an approved
personal statement or a novelty claim. The factual claim ledger is separate.

We want to start with a small task whose mechanism can be explained from end to
end. Here the question is simple: which phase pattern did one photon encounter?
The input, hidden operation, receiver and recorded answer can all be written
as explicit optical objects. That makes it possible to understand why a change
helps, what it costs, and where the explanation stops applying.

The receiver should be no more complicated than the task requires. When the
model allows the same decoder to remain optimal, changing the incident
amplitudes is an appealing experimental rule. It gives the laboratory a clear
comparison: keep the receiver fixed, change the preparation for the measured
loss and required reliability, and count what happens. The point is the complete
operational simplification, rather than adding a complicated framework around a
small demonstration.

A quantum benefit also needs a precise resource comparison. Calling the source
quantum, or showing a sharp interference pattern, does not establish that
benefit. We must identify the input budget, the accessible outputs, the allowed
competing sources and receivers, and every failed attempt. Classical light is
therefore useful both for commissioning the optics and for testing the limits
of the eventual scientific interpretation. Those are different roles and should
be reported separately.

The negative regions belong in the same account. If loss or a reliability
requirement makes a classical strategy better than the whole declared photon
class, that result helps explain the mechanism's boundary. If a systematic
phase error requires another receiver, it also tells us something useful. We
should not hide either outcome by selecting favorable inputs, detected events
or a weak comparison.

The earlier coherent-learning discussion helped motivate a search for a simple
idea. The present task stands on its own as single-use optical reading. Its
value should be judged through explicit assumptions, understandable predictions,
reproducible calculations and experiments that can distinguish success from
failure.
